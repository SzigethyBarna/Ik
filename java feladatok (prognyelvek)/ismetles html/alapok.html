2. RÉSZLETES ÚTMUTATÓ ÉS RENDELTETÉS

A) Sima Tömb (Array) 📦

Mikor látod? A vizsgafeladatok metódusai/konstruktorai szinte mindig tömböt kapnak paraméterként (pl. BaseSpell[] list).

  • Fix méretű, nem lehet hozzáadni elemet, csak a meglévő indexekre pakolni!
  • Túlindexelés hiba: ArrayIndexOutOfBoundsException (pl. ha a tömb 3 elemű, és te a parts[3]-at kéred).

B) List vs. ArrayList (Az Interfész és a Megvalósítás) 📋

A List egy **Interfész** (egy elméleti tervrajz), az ArrayList pedig a **Konkrét Osztály**, ami megvalósítja ezt a tervrajzot.

  • A szabály: Típusként (bal oldalon) nyugodtan használhatod a sima List-et, de példányosítani (jobb oldalon) csak a konkrét ArrayList-et szabad!
  • Megengedi a duplikációt és megőrzi a sorrendet. Elem elérése mindig: lista.get(i).

C) HashSet (Az Egyedi VIP Halmaz) 🎟️

Mikor használod? Ha a feladat kiköti: "csak az egyedi elemek", vagy "duplikáció kiszűrése".

  • Kiszűri a duplikációt. Ha kétszer adod hozzá ugyanazt, a második .add()-ot némán figyelmen kívül hagyja.
  • SZIGORÚAN TILOS az asd.get(i) vagy asd[i]! Csak for-each ciklussal tudsz végigmenni rajta: 
    for (String nev : nevekHashSet) {
    System.out.println(nev);
}

D) HashMap (A Kulcs-Érték Szótár) 📖

Mikor használod? Ha dolgokat kell összekapcsolnod párba. Pl. "Rendszám" -> "Autó objektum".

  • A Kulcsnak teljesen egyedinek kell lennie. Az Érték lehet ugyanolyan.
  • A .put(kulcs, ertek) felülírja a korábbi értéket, ha a kulcs már létezett!
  • Primitív típusok (int, double, boolean) TILOSAK a gyémánt zárójelben! Helyette csomagoló osztályok kellenek: Integer, Double, Boolean.

3. A ZH LEGNAGYOBB "KÓDGYILKOS" HIBÁI

🚨 1. A Halálos "new List<>()" hiba

Mivel a List egy interfész, **nem lehet közvetlenül példányosítani**! A jobb oldalon MINDIG ArrayList kell!

❌ List<BaseSpell> lista = new List<>();   ➔   Fordítási hiba!
✅ List<BaseSpell> lista = new ArrayList<>();   ➔   TÖKÉLETES!

🚨 2. "asd[i]" vs "asd.get(i)" elcserélése

Ha a függvény tömböt kapott, de te listaként kezeled, vagy fordítva, a Java azonnal elszáll:

Tömb esetén: ❌ parts.get(2)   ➔   ✅ parts[2]
Lista esetén: ❌ spells[idx]   ➔   ✅ spells.get(idx)

🚨 3. String tartalom összehasonlítása == jellel

Parancsok értelmezésénél a == memóriacímet néz, a tartalomra MINDIG .equals() kell!

❌ if (parancs == "cast")
✅ if (parancs.equals("cast"))

🚨 4. Értékadás egy függvényhívásnak kasztoláskor

Nem adhatsz értéket egy get() metódusnak. A kasztolt objektumot külön változóba kell kimenteni!

❌ this.spells.get(idx) = (ChainSpell) this.spells.get(idx);
✅ ChainSpell cs = (ChainSpell) this.spells.get(idx);
    cs.setAuraColor(parts[2]);

Konstruktor: Tömb átpakolása ArrayList-be (List típussal)

// Az adattag lehet sima List interfész típusú is!
private final List<BaseSpell> spells;

public MagicAcademy(BaseSpell[] bss) {
    this.spells = new ArrayList<>(); // Példányosítani már ArrayList-tel kell!
    for(BaseSpell bs : bss) {
        this.spells.add(bs);
    }
}
